Make every site look designed for its subject, not templated.
- Plan first: audience, main job of the page, sections, real believable copy (no lorem ipsum).
- Pick one accent color, a clear type scale, generous spacing, one memorable hero. Use CSS variables in src/styles.css.
- Landing pages: hero, key sections (about, features/programs, gallery, testimonials, contact), footer, clear call to action.
- Add hover/press states and focus outlines. Use inline SVG or CSS shapes for icons and art.
- Split big UIs into components (src/Header.jsx, src/Hero.jsx ...), App.jsx last.

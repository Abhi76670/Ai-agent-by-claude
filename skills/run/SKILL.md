How to run and tell the user to run a project.
- Default React setup: open index.html through a static server: npx serve . (or make run).
- Vite/React: npm install && npm run dev. Next.js: npm install && npm run dev (http://localhost:3000). Flutter: flutter pub get && flutter run -d chrome.
- Check tools before relying on them: <run>node -v</run>, <run>which flutter</run>. Do not assume anything is installed.

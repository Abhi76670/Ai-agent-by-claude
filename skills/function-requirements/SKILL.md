For every function or feature, work out what it requires before coding it.
- Purpose in one line. Inputs (type, required or optional, validation). Output or visible result. State and storage it touches. Edge cases (empty, invalid, duplicate, very long). Error and success messages. Dependencies on other files.
- Put this short list in requirements.md under the feature name, then implement all of it.
- If the user asks "what is required for X", answer with this list and do not build.
